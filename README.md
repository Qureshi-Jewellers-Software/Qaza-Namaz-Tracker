# Qaza Namaz Tracker

Android app (Kotlin + Jetpack Compose) jo qaza namazon aur qaza rozon ka hisaab rakhti hai.

## APK kaise milegi
1. Repo mein **Actions** tab kholein.
2. Sab se upar wala **Build APK** run kholein (hara ✓ hona chahiye).
3. Neeche **Artifacts** mein `qaza-namaz-tracker-apk` download karein.
4. Zip kholein aur `app-debug.apk` phone par install karein.

## Folders
- `app/` – Android app ka code
- `supabase/` – database setup (SQL)
- `.github/workflows/` – APK banane ki automatic setting
